## 二 · 任务定义

- **要模型学会什么**：通用问答（自然科学 / 历史文化 / 地理 / 生活百科 / 计算机）
- **输入格式**：Alpaca 三字段 —— `instruction` / `input` / `output`
- **输出格式**：同左，`output` 为期望回答
- **一条样本长什么样**：

```
【英文样本（来自 alpaca-cleaned）】
instruction: Edit the following sentence so that it is in the simple past tense:
             "Today, I goes to the store to buy eggs."
input:       (空)
output:      Yesterday, I went to the store to buy eggs.

【中文样本（Ollama qwen3:8b 生成）】
instruction: 光合作用的过程是什么？
input:       (空)
output:      光合作用是植物、藻类和某些细菌将光能转化为化学能的过程。
             主要分为光反应和暗反应两个阶段……
```

## 三 · 构造过程（**这一节最关键**）

| 步骤 | 怎么做的 | 产出 | 砍掉 |
|---|---|---|---|
| 1. 采集（开源） | `datasets_open_source_data.py` 从 HF 镜像下载 `yahma/alpaca-cleaned` | **51760 条** | — |
| 2. 采集（生成） | `datasets_generated_data.py` 调本地 Ollama `qwen3:8b`（temperature 0.8, num_predict 24576） | 目标 120 条 → **实得 94 条** | **26 条**（生成失败/为空） |
| 3. 清洗 | `datasets_clean_json.py`：用 `raw_decode` 逐对象解析（因为原始文件**不是合法 JSON**），补全缺失字段，剔除 instruction 与 output 双空的条目 | 开源侧 51760 条全部有效 | 0 条 |
| 4. 抽样 | 同上脚本 `max_samples=100`，**随机抽**（`random.sample`，非顺序取前 N） | 开源 **100 条** | 51660 条未用 |
| 5. 合并 | `datasets_merge_script.py`：开源 100 + 生成 94 | **194 条** | — |
| 6. 质检 | `datasets_check_data_quality.py` | 报告见下 | — |

- **清洗规则**（可复现）：① `instruction` 缺失时回退读 `question` 字段 ② `output` 缺失时回退读 `answer`
  ③ 两者皆空即判定无效并丢弃 ④ 所有字段 `str().strip()`
- **去重口径**：⚠️ **质检报告显示「重复检查: 0 个」，即未做实质性去重**
- **质检方式**：脚本自动检查（空值 / 长度 / 格式 / 重复 / 乱码五类），**无人工抽检**

## 五 · 已知缺陷（**必须写，不许省略**）

1. ⚠️ **中英混合，且是「意外」混的** —— 开源部分是英文，生成部分是中文（因为提示词用中文写的）。
   这个数据集训出来的模型，行为会**在中英之间摇摆**，无法预期。
   **这不是设计，是两条线各自完工后直接相加的结果。**

2. ⚠️ **存在极短输出（3–7 字符）** —— 第 39 条 output 只有 **3 个字符**。
   这类样本会让模型学到「可以给极短回答」，是**退化样本**。质检报告标出来了，但**没有清理**。

3. ⚠️ **生成部分是同源蒸馏** —— 94 条全部出自**同一个模型**（`qwen3:8b`）在 `temperature=0.8` 下的输出。
   用它训出的模型，学的是 **qwen3:8b 的风格与偏见**，不是「正确知识」。
   而且**没有任何人工审核**这 94 条的对错。

4. ⚠️ **未去重** —— 质检的重复检查是 0，但那是「完全匹配」口径；
   语义近似但字面不同的重复**没有被检查**。

5. ⚠️ **领域覆盖不均** —— 生成侧的 5 个主题（自然科学/历史文化/地理/生活百科/计算机）
   是**随手写的**，没有依据任何需求分析；开源侧 100 条是**随机抽**的，
   抽到什么领域完全随机。两侧领域**没有任何对齐**。

6. ⚠️ **`input` 字段 81.4% 为空** —— 194 条里只有 36 条有上下文。
   如果目标场景是多轮或带上下文的问答，这个数据集**覆盖不到**。

7. **不适合的用途**：⛔ **商业产品**（`CC BY-NC 4.0` 限制）、
   ⛔ **中文能力的严肃评测**（中文只有 94 条且是同源生成）、
   ⛔ **任何需要「数据配比经过设计」结论的实验**（本来就没配比）

## 七 · 复现方式

```bash
# 1. 下载开源数据（需要 HF 镜像）
export HF_ENDPOINT=https://hf-mirror.com
python scripts/datasets/datasets_open_source_data.py        # → datasets_open_source_data.json (51760 条)

# 2. 生成数据（需要本地 Ollama + qwen3:8b）
ollama pull qwen3:8b
python scripts/datasets/datasets_generated_data.py          # → datasets_generated_data.json (94 条)

# 3. 清洗 + 随机抽 100
python scripts/datasets/datasets_clean_json.py              # → *_cleaned_100.json

# 4. 合并
python scripts/datasets/datasets_merge_script.py            # → my_dataset.json (194 条)

# 5. 质检
python scripts/datasets/datasets_check_data_quality.py      # → data_quality_report.txt
```

> ⚠️ 第 1、2 步依赖外部服务与**非确定性**（随机抽样 + 模型生成温度 0.8），
> **重跑不会得到逐条相同的 194 条**。可复现的是**流程与统计量**，不是具体条目。
