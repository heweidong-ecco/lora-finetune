## 二 · ⛔ 读之前必须知道的三件事

### 1. 本库**不包含**上游 LLaMA-Factory 的任何代码

`上游-LLaMA-Factory-勿改.md` 列了哪些是官方仓库自带的文件（`src/` `tests/` `examples/` 里的
`qwen3_*.yaml` 等）。**那些不是本人的代码，本库也没有收录它们。**
本库自己的代码以 MIT 授权（见 `../LICENSE`）。

### 2. `整合报告` 里的路径**指向仓库外**

报告是「文件是怎么从归档搬进仓库」的记录，里面的 `AutoDL下载/…`、`本机/…`
都是**相对原始素材归档**的路径，不是仓库内路径。
归档位置写在报告开头。

### 3. 两份 `autodl*.md` 是**历史原文**

内容**保留原样**（只做了两处加工：清理了一处明文密钥、补回丢失的 Markdown 代码围栏）。
里面出现的命令是**当时的**，路径 `/root/autodl-fs/…` **今天已经不存在**。
