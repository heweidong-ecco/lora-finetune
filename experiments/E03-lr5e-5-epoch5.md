# 实验 E03 · 把学习率降到 5e-5、epochs 加到 5

## 一 · 假设

> **一句话**：我改 **`learning_rate` 2e-4 → 5e-5 并把 `epochs` 3 → 5**，
> 预期 **训练更稳、loss 更低**，因为 **小学习率收敛更细，多跑几轮能吃透数据**。

- **本实验属于哪一类**：
  - [ ] 改数据
  - [x] **改参数**（lr + epochs）
  - [ ] 其他

## 二 · 变量

| | 值 |
|---|---|
| **自变量** | ⚠️ **改了两个**：`learning_rate` 2e-4 → 5e-5；`num_train_epochs` 3 → 5 |
| 对照组 | **E01 baseline** |
| 控制变量 | 数据集（500 条同一份）、rank 8、alpha 16、bs 2、ga 4、cutoff_len 1024、template qwen、基座 Qwen3-8B |

> ⚠️ **模板明确写着「一次只改一个。同时改两个，就分不清是哪个起的作用 —— 实验白做」。**
> 本实验**违反了这条**。所以即使出现差异，**也无法归因到 lr 还是 epochs**。
> **这是一个设计缺陷，不是可以含糊过去的细节。**

**对照样例**：❌ **没有**

> ⚠️ **这组的 loss 数字尤其不能横比。**
> E03 跑了 **5 个 epoch**，E01 只跑 **3 个** —— 「末值 loss」是在**不同的训练步数**上取的。
> 步数不同、lr 调度（cosine）的衰减轨迹也不同，**两个末值 loss 不是同一个东西**。
> 再叠加 E01 独有的早停/评估配置，**这组对比的可比性最弱**。

## 六 · 结论

- **假设成立吗**：❌ **不成立**（预期 loss 更低，实际更高且慢得多）
- **一句话结论**：**降 lr + 加 epochs 在本数据集上没有收益**：
  loss 高 77%、耗时 2.6 倍、计算量（FLOPs）多 82%
- **意外发现**：
  - 三次实验的 **runtime 单调递增**：E01 181.5 s < E02 301.0 s < E03 479.1 s
  - 三次实验的 **loss 也单调递增**：E01 0.5603 < E02 0.8462 < E03 0.9941
    👉 **「越调越差、越调越慢」** —— 而基线（什么都没调的那个）反而是最好的
  - ⚠️ 这个现象**很值得写进 README**，但**必须先补上人工判断**才能下结论，
    否则只是「loss 变化」，无法说明输出质量
- **意外发现（设计层面）**：
  - 本实验**同时改了两个变量**，违反模板要求 → **即使有差异也无法归因**
  - 若要重做，应拆成 **E03a（只降 lr）** 与 **E03b（只加 epochs）**
