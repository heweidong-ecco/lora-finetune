# 实验 E04 · 固定全部参数，只换数据集

> ⬜ **状态：方案已就绪，待跑**（需要有 GPU 的环境）
> 建立：2026-09-16 ｜ **设计修正：2026-09-16**（见 §二 的「为什么改设计」）
>
> ⭐ **这是本库最重要的一组实验** —— E01~E03 全在改参数，**一次改数据的都没有**，
> 所以本库一直关注的判断「**数据质量 ≫ 超参数**」**从未被检验过**。E04 就是来补这个的。

## 一 · 假设

> **一句话**：我**只换数据集、其余一切不动**，预期 **输出质量会明显变化**；
> 若变化幅度**大于** E01~E03「只改参数」带来的变化，则支持「数据 ≫ 参数」。

- **本实验属于哪一类**：
  - [x] **改数据**（数据集内容 / 配比 / 清洗规则）
  - [ ] 改参数
  - [ ] 其他

## 二 · ⚠️ 为什么改设计（**这一节记录一次被推翻的设计**）

### 早先的设计错在哪

原方案是 **A 组 = alpaca 抽 194 ／ B 组 = qa-general 全部 194**。
写好后实测两组，发现它们在**三个维度上同时不同**：

| | 数据来源 | **语言** | instruction 均长 |
|---|---|---|---|
| A（alpaca） | `yahma/alpaca-cleaned` | **0% 中文** | ~81 |
| B（qa-general） | 开源 + 本地模型生成 | **48% 中文** | 39.9 |

👉 **即使跑出差异，也分不清是「来源」「语言」还是「质量」造成的** ——
**归因不成立**，实验等于白做。

> 📌 这违反的本实验自己定的第一条原则：「除了数据集，其余一个都不许改」。
> **语言也是数据集的一部分，不能当成"没改"。**

### 现在的设计：唯一变量 = 抽样代表性

| | 数据来源 | 语言 | 条数 | 抽样方式 |
|---|---|---|---|---|
| **A 组** | `yahma/alpaca-cleaned` | 英文 | **194** | 从**全部 51760 条**里随机抽 |
| **B 组** | `yahma/alpaca-cleaned` | 英文 | **194** | 从**前 550 条**那个区块里抽 |

**同源 ✅ 同语言 ✅ 同条数 ✅ —— 只有抽样方式不同。**

**B 组为什么取「前 550 条」**：正是 `datasets/数据卡-alpaca500.md` §五-1 实测出
**`instruction` 均长偏出总体 +31%** 的那个区块。
👉 **所以这组实验同时在验证那个抽样偏倚到底有没有实际影响。**

**实测两组分布**（`make_e04_datasets.py` 自检输出）：

```
instruction 均长：A = 63.1    B = 84.9     （B 来自有偏区块，明显更长，+35%）
A∩B 重合：0 / 194 条
```

### 三个设计要点（不满足就没意义）

1. **两组条数必须相同（都 194）**
   若拿 194 vs 500 比，就**混淆了「数据内容」和「数据条数」** —— 归因不成立。
2. **抽样必须确定**（可复现）
   → `scripts/datasets/make_e04_datasets.py` 用**固定种子**，输出已验证**两次跑 MD5 一致**。
3. **除了数据集，其余一个都不许改**
   → 两配置应**逐行相同，只有 `dataset` 与 `output_dir` 两行不同**（`output_dir` 不同只为避免互相覆盖）。
   跑之前先 `diff` 确认。

## 八 · 跑之前的环境准备

```bash
# 1. 生成两个 194 条数据集（确定性；需要一个含全部 51760 条的文件，见脚本文件头）
python scripts/datasets/make_e04_datasets.py
#    → datasets/alpaca-clean-500条/E04-A组-194条.json   （从全量随机抽）
#    → datasets/alpaca-clean-500条/E04-B组-194条.json   （从前 550 区块抽）

# 2. 确认配置只差两行（dataset / output_dir）
diff configs/E04-A组-random随机194.yaml configs/E04-B组-front550前段194.yaml

# 3. 把两个数据集注册进 LLaMA-Factory 的 data/dataset_info.json（条目见配置头部）

# 4. 训练（两次）
llamafactory-cli train configs/E04-A组-random随机194.yaml
llamafactory-cli train configs/E04-B组-front550前段194.yaml

# 5. 评测 —— 见 experiments/E05-人工判断.md（三组对比）
```

> ⚠️ `configs/` 里的 `model_name_or_path` 与 `output_dir` 是**原环境（AutoDL）的路径**，
> 直接跑会失败，**需要改成你自己的路径**。
