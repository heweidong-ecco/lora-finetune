# 训练参数速查
# 参数	本次训练值	含义	调优方向
# lora_rank	8	便签纸的大小	不够就升到16，过拟合就降到4
# lora_alpha	16	便签纸的墨水浓度	通常保持 rank 的2倍
# learning_rate	2e-4	每次调整的步长	不收敛就降到5e-5
# num_train_epochs	3	把数据集看几遍	loss还在降就加到5
# per_device_train_batch_size	2	每次看几条数据	OOM就降到1
# gradient_accumulation_steps	4	攒几次再一起更新	batch_size降了，这个就翻倍
# cutoff_len	1024	每条数据最大token数	长文本任务需要加大
# bf16	true	混合精度训练	省显存，几乎不影响效果
# save_total_limit	2	只保留最近2个检查点	防止磁盘被撑满
